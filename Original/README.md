# SystemBanner 1.1 (original edition)

This folder keeps the files of the original SystemBanner 1.1 by Aaron Wawrzyniak, unchanged except for the binary path in `InstallSystemBanner.bat`. They are kept for reference and for Windows 10/11.

For Windows XP, use the `XP` folder at the repository root instead.

| File | Content |
|---|---|
| `SystemBannerSetup.msi` | Original MSI installer (.NET Framework 4.7.2). |
| `InstallSystemBanner.bat`, `RemoveSystemBanner.bat` | Original install and removal scripts, run as administrator. |
| `Binaries/` | Original SystemBanner 1.1 binaries used by `InstallSystemBanner.bat`. |
| `Group Policy/` | ADMX/ADML Group Policy templates for Windows 10/11 and Windows Server. |
| `Images/` | Original screenshots. |

The original project, its documentation and its latest version are at https://github.com/awawrzyniak10/SystemBanner.
